**NIGHT VAULT** — a top-down stealth infiltration game. Slip past patrols and cameras, recover every data core, and reach extraction unseen. Built for make.fun's "Make the best stealth game" bounty.

Two missions (Vault Annex, Server Vault) with learnable guard patrols, wall-clipped vision cones, sweeping cameras, shadow tiles that hide you, amber light pools that expose you, noise-based hearing, a detection meter that gives you a chance to recover, alarms that clear when you break line of sight, and a ghost bonus for finishing with zero alarms. Ranks: GHOST → SHADOW → OPERATIVE → BLUNT INSTRUMENT.

Vanilla JavaScript + Canvas in a single HTML file: zero dependencies, zero network requests, all art drawn with code, all sound synthesized with WebAudio.

**Controls:** WASD / arrow keys to move · hold SHIFT to sneak (silent, harder to spot) · P pause · R restart · M mute · Enter to start.

## Run it

```sh
# play: open game/index.html in a desktop browser (Chrome recommended)
# build the entry dossier:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
